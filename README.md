# ♟️ Chess Hero Section Clone

A recreation of the hero section of a modern online chess platform built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS v4**.

The primary goal of this project was to recreate the look, feel, and animations of the original landing page as closely as possible while learning modern animation techniques and working with a chess library.

---

## 🚀 Tech Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS v4
- Framer Motion (Motion)
- Chess.js
- React Chessboard
- Canvas Confetti

---

## ✨ Features

- Responsive hero section
- Smooth entrance animations
- Animated chessboard
- Chess move validation using Chess.js
- Interactive React Chessboard
- Gradient text animations
- Floating background chess piece animations
- Confetti celebration effects
- Mobile-friendly layout
- Modern UI inspired by the original design

---

## 🧩 Chess Logic

The chess functionality is implemented using:

- **Chess.js** for game rules and move validation.
- **React Chessboard** for rendering the interactive chessboard.

This allowed me to focus on building the UI and interactions while relying on well-tested chess logic.

---

## 🎨 Animations

This project contains numerous custom animations created using:

- Framer Motion

Some of the animations include:

- Word-by-word text reveals
- Blur and fade transitions
- Hero content entrance animations
- Floating chess piece background
- Hover interactions
- Smooth board transitions
- Confetti effects

A significant amount of time was spent fine-tuning timings, easing curves, positioning, and responsiveness to closely match the original website.

---

## 🤖 AI Usage

AI was used as a learning assistant throughout this project.

Approximately **30%** of the development involved using AI to:

- Better understand unfamiliar APIs
- Learn Framer Motion techniques
- Understand Chess.js usage
- Debug animation issues
- Explore different implementation approaches

The remaining implementation—including integration, UI development, animation adjustments, debugging, responsiveness, and overall project structure—was completed manually while referencing the official documentation.
